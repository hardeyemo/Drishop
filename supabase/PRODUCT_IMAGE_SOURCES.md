# Product image sources and usage

All 48 files in `product-image-assets/` are cropped WebP downloads from individual
Unsplash photo pages. Every selected photo page labels its image as free to use under the
[Unsplash License](https://unsplash.com/license). That license permits commercial use and
does not require attribution. The downloaded images are local project assets; the storefront
does not hotlink Unsplash.

The images are illustrative stock photos for the fictional/demo catalogue. They are not
manufacturer images and do not prove that a real product has the depicted specifications.
Replace them with authorized vendor photos before using these sample listings to represent
actual products. Unsplash's license does not grant trademark, model, or property rights beyond
the image copyright license; review visible marks before using an image in a live listing.

## Download again

The verified source photo IDs and filenames are kept in `download-product-images.mjs`.
From the project root, run `node supabase/download-product-images.mjs` for all 48, or
`node supabase/download-product-images.mjs --new` for only the 30 added photos. It downloads each
image as a 900 × 1125 WebP with the full image contained on a white background, validates
the response type and file signature, and saves it under its exact slug filename. It contacts Unsplash only during this explicit
download step; the site itself serves the later Supabase Storage copies.

Then follow [PRODUCT_IMAGES.md](PRODUCT_IMAGES.md) to upload and link the local files using
the existing Supabase uploader.
